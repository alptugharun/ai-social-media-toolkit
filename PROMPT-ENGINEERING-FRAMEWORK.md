# Prompt Engineering Framework

A practical framework for designing clear, reusable and reliable prompts for content creation, research, marketing, visual generation and workflow automation.

Created by **Alptuğ Harun**.

This framework is designed for creators, social media professionals, marketers and digital teams who want to move beyond random prompting and build repeatable AI workflows.

---

## Framework Overview

A strong prompt should define:

**Role → Objective → Context → Inputs → Constraints → Output Format → Quality Criteria → Review**

The goal is not to write the longest prompt.

The goal is to provide the AI with enough structure to produce a useful and repeatable result.

---

## 1. Define the Objective

Every prompt should begin with a clear objective.

Ask:

- What should the AI produce?
- Why is the output needed?
- Who will use it?
- What decision or action should it support?
- What would make the output useful?

Weak objective:

Create social media content.

Stronger objective:

Create a short-form educational content concept designed to increase saves and shares among people interested in AI-supported content creation.

The more specific the objective, the easier it becomes to evaluate the result.

---

## 2. Assign the Right Role

A role can help define the perspective and expertise expected from the model.

Examples:

- Social media strategist
- Content researcher
- Creative director
- Digital marketing specialist
- Editorial assistant
- Brand strategist
- Pinterest researcher
- SEO content planner
- Visual art director

Roles should support the task.

They should not replace clear instructions.

A vague task will remain vague even if the prompt begins with an impressive title.

---

## 3. Provide Context

AI performs better when it understands the environment surrounding the task.

Useful context may include:

- Brand identity
- Audience
- Platform
- Product or service
- Previous content
- Campaign objective
- Tone of voice
- Industry
- Geographic market
- Competitors
- Available tools
- Production limitations

Context should explain what the AI needs to know before making decisions.

---

## 4. Define the Audience

The same topic should not be communicated the same way to every audience.

Define:

- Age range
- Interests
- Knowledge level
- Problems
- Motivations
- Objections
- Platform behavior
- Language style

Example:

Instead of:

Write about Canva.

Use:

Explain a Canva workflow for social media creators who already know the basics but want to integrate generative AI into their production process.

---

## 5. Specify the Platform

Content should be adapted to the environment where it will be published.

Different platforms reward different behaviors.

Examples:

### Instagram

Consider:

- Strong opening
- Mobile-first communication
- Saves
- Shares
- Reels
- Carousels
- Visual hierarchy

### Pinterest

Consider:

- Search intent
- Keywords
- Visual discovery
- Evergreen potential
- Seasonal planning
- Website traffic

### LinkedIn

Consider:

- Professional insight
- Experience
- Industry relevance
- Authority
- Discussion

### Blog

Consider:

- Search intent
- Structure
- Depth
- Internal linking
- Long-term discoverability

The platform should be part of the prompt whenever it affects the output.

---

## 6. Provide Inputs

Do not expect the model to invent information that already exists.

Provide useful inputs such as:

- Research notes
- Product information
- Statistics
- Brand guidelines
- Content examples
- Keyword lists
- Audience questions
- Links
- Previous drafts
- Campaign briefs
- Visual references

Better inputs usually produce better outputs.

---

## 7. Add Constraints

Constraints help reduce generic output.

Useful constraints include:

- Word count
- Video duration
- Number of ideas
- Character limits
- Language
- Tone
- Format
- Platform dimensions
- Forbidden phrases
- Number of hashtags
- Required sections
- Visual consistency rules

Example:

Instead of:

Write a Reel script.

Use:

Create a Turkish Reel script that can be spoken naturally in approximately 30 seconds. Use a strong hook, short sentences, one clear idea and a concise CTA.

---

## 8. Define the Output Format

Tell the model exactly how the answer should be structured.

Possible formats:

- Table
- Checklist
- Script
- Content calendar
- Markdown
- Headline list
- Creative brief
- Research summary
- Prompt
- Caption
- Workflow
- Step-by-step guide

A structured output is easier to reuse in a production workflow.

---

## 9. Define Quality Criteria

Describe what a successful result should feel like.

Possible criteria:

- Clear
- Accurate
- Practical
- Natural
- Specific
- Non-repetitive
- Platform-native
- Brand consistent
- Easy to understand
- Actionable
- Visually coherent

Quality criteria help the AI understand what should be prioritized.

---

## 10. Build Reusable Prompt Templates

Repeated tasks should not require rewriting the entire prompt every time.

Create reusable structures.

A useful template:

**ROLE**

Who should the AI behave as?

**OBJECTIVE**

What should be achieved?

**CONTEXT**

What background information matters?

**AUDIENCE**

Who is the output for?

**INPUT**

What information should be used?

**CONSTRAINTS**

What rules must be followed?

**OUTPUT**

What format should be returned?

**QUALITY**

What makes the result successful?

This structure can be reused across many tasks.

---

## 11. Use Prompt Variables

Reusable prompts become more useful when fixed instructions are separated from variables.

Possible variables:

- Topic
- Platform
- Audience
- Format
- Objective
- Duration
- Brand
- Style
- Keyword
- Campaign
- Product

Example structure:

Topic: [TOPIC]

Platform: [PLATFORM]

Audience: [AUDIENCE]

Objective: [OBJECTIVE]

Format: [FORMAT]

This makes the workflow easier to scale.

---

## 12. Prompt Chaining

Complex tasks often perform better when divided into stages.

Instead of asking AI to complete everything at once, use a sequence.

Example:

**Research**

↓

**Identify opportunities**

↓

**Select topic**

↓

**Generate hooks**

↓

**Choose direction**

↓

**Create script**

↓

**Create visual direction**

↓

**Review**

This is often more reliable than one enormous prompt.

---

## 13. Generate Multiple Options

Do not depend on the first answer.

For creative work, request alternatives.

Examples:

- 10 hook options
- 5 headline directions
- 3 visual concepts
- 3 CTA variations
- 5 content angles

Then compare and select.

A useful workflow is:

**Generate → Shortlist → Refine → Human Select**

---

## 14. Add a Review Stage

A prompt workflow should include quality control.

Ask the model or human reviewer to check:

- Accuracy
- Repetition
- Unsupported claims
- Tone
- Brand consistency
- Platform fit
- Missing information
- Weak assumptions
- Clarity
- Originality

AI-generated content should not automatically move directly to publishing.

---

## 15. Visual Prompt Structure

Visual generation prompts benefit from a structured approach.

Useful components include:

- Subject
- Pose
- Composition
- Camera angle
- Lens
- Environment
- Lighting
- Color direction
- Material
- Mood
- Style
- Detail level
- Aspect ratio

A useful visual prompt structure:

**Subject + Pose + Composition + Environment + Lighting + Camera + Style + Detail + Format**

When creating a visual series, define what should remain constant and what should change.

---

## 16. Maintain Visual Consistency

For multi-image content, consistency should be intentional.

Keep constant when necessary:

- Character
- Face
- Pose
- Camera angle
- Composition
- Scene structure
- Lighting direction

Change only the variables required by the concept.

Examples:

- Historical era
- Clothing
- Artistic style
- Environment
- Season
- Color treatment

This creates a stronger visual identity across a series.

---

## 17. Research Prompts

Research prompts should not only request information.

They should define:

- Topic
- Time period
- Geography
- Sources
- Questions
- Comparison criteria
- Evidence requirements
- Output structure

Useful research outputs may include:

- Trend summaries
- Opportunity maps
- Competitor analysis
- Keyword clusters
- Content gaps
- Risk notes
- Source lists

Research should support a decision.

---

## 18. Content Prompts

A content prompt should usually define:

- Audience
- Platform
- Objective
- Topic
- Hook
- Tone
- Format
- Length
- CTA

A strong content prompt connects creative execution with strategy.

---

## 19. Automation Prompts

Prompts used inside automation systems should be more predictable than conversational prompts.

They should define:

- Input structure
- Required output
- Error handling
- Missing information behavior
- Formatting rules
- Approval requirements
- Escalation conditions

Automation prompts should prioritize consistency.

---

## 20. Human Control

Prompt engineering is not about removing humans from the process.

Human judgment is still needed for:

- Strategy
- Brand positioning
- Ethical decisions
- Fact checking
- Creative direction
- Final approval
- Context interpretation

AI should accelerate execution.

Humans should control direction.

---

## Prompt Design Loop

A strong prompt improves over time.

Use this cycle:

**Write → Test → Review → Identify Failure → Refine → Save → Reuse**

Do not discard a useful prompt after one use.

Turn successful prompts into reusable assets.

---

## Core Principle

Prompt engineering is not about discovering one magical sentence.

It is about creating a structured communication system between the human and the AI.

The strongest prompt systems combine:

**Clear Objective + Useful Context + Strong Constraints + Structured Output + Human Review**
