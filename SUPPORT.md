# Support

Use the smallest path that matches your problem.

## I do not know where to start

Use:

- [START-HERE.md](START-HERE.md) for the fastest route;
- [How to Use Everything](docs/HOW-TO-USE-EVERYTHING.md) for full step-by-step guidance;
- [Two-Minute Demo](examples/TWO-MINUTE-DEMO.md) if you want proof before installation.

## I have a question, idea or example

Use **GitHub Discussions** for open-ended conversation:

https://github.com/alptugharun/ai-social-media-toolkit/discussions

Use:

- **Q&A** for setup, usage and compatibility questions;
- **Ideas** for feature/workflow proposals tied to a real job;
- **Show and tell** for things you built, adapted or learned;
- **General** for broader AI-workflow conversation.

Read [COMMUNITY.md](COMMUNITY.md) for category guidance.

## Something is broken

Open a **Bug report**.

Include:

- the skill/tool/workflow;
- runtime/platform and version;
- reproduction steps;
- expected vs observed behavior;
- the smallest useful error/log excerpt.

Remove credentials, private account IDs and client data.

## The workflow works, but I hit friction

Open **Workflow feedback**.

The most useful report is the **first** point where you became confused, blocked or wanted a deeper version.

## I want to contribute

Start with:

- [Contributing](CONTRIBUTING.md);
- [Good first issue: runtime verification](https://github.com/alptugharun/ai-social-media-toolkit/issues/38);
- [Good first issue: creator workflow example](https://github.com/alptugharun/ai-social-media-toolkit/issues/40).

## Security or sensitive vulnerability

Read [SECURITY.md](SECURITY.md) before posting details publicly.

Do not publish secrets, tokens, credentials or sensitive account information in an issue.

## I want a new feature

Describe the **job**, not just the feature.

Good request:

> I use the Pinterest workflow for seasonal content. After keyword clustering I still have to manually map seven Pin roles to destination URLs. I want a reusable output format that keeps that mapping explicit.

Weak request:

> Add a Pinterest AI feature.

## I want a paid / managed version

Describe the deeper outcome you would pay to avoid implementing yourself. That evidence is used by the project's [growth and productization gates](references/GROWTH-PRODUCTIZATION-GATES.md).

Commercial interest does not automatically move useful open-core functionality behind a paywall.
