## Discussions

Community conversations live in GitHub Discussions:

https://github.com/alptugharun/ai-social-media-toolkit/discussions

Use the category that best matches your goal:

- **Announcements** — releases and maintainer updates.
- **General** — open-ended project and AI-workflow conversation.
- **Ideas** — proposals based on a real job or friction point.
- **Q&A** — setup, usage and compatibility questions.
- **Show and tell** — real experiments, adaptations and results.

The pinned welcome discussion is:

https://github.com/alptugharun/ai-social-media-toolkit/discussions/54

## Issues are for actionable work

Use GitHub Issues when something should become trackable work:

- reproducible bugs;
- scoped workflow feedback;
- contributor tasks;
- runtime verification;
- concrete implementation work.

Use Discussions for questions, ideas, examples and open-ended conversation.

## How to ask a strong question

Include:

1. what you are trying to achieve;
2. what you already tried;
3. where the workflow stopped helping;
4. runtime/platform when relevant;
5. the smallest useful error or example.

## How to share a useful result

Tell us:

- what you built;
- which resource you used;
- what result you reached;
- what confused you;
- whether you would use it again.

## Safety

Never post:

- API keys;
- passwords;
- access tokens;
- private client data;
- confidential company information;
- sensitive account identifiers.

## Community standard

Be specific, constructive and evidence-aware.

No spam, fake testimonials, fake usage claims, star-for-star exchanges or engagement manipulation.

See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) for the full community standard.
