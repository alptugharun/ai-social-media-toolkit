# Reusable Prompt Template

A fill-in structure for creating prompts that are easier to test, improve and reuse.

## Prompt Blueprint

**Role / Context**  
You are acting as:  
[Role]

**Objective**  
Your task is to:  
[Clear objective]

**Audience**  
The output is for:  
[Audience]

**Inputs**  
Use the following information:  
[Paste data, references, source material or brief]

**Requirements**  
The output must:

- [Requirement 1]
- [Requirement 2]
- [Requirement 3]

**Constraints**  
Do not:

- [Constraint 1]
- [Constraint 2]

**Tone / Style**  
Use:  
[Tone, language, style]

**Output Format**  
Return the result as:  
[Table / Script / Checklist / Markdown / JSON / Structured sections]

**Quality Criteria**  
Before finalizing, check:

- Accuracy
- Relevance
- Specificity
- Brand fit
- Platform fit
- Missing information

## Visual Prompt Variant

Use:

**Subject + Composition + Environment + Lighting + Camera + Style + Detail + Format**

Example structure:

Subject: [Main subject]  
Composition: [Composition]  
Environment: [Scene]  
Lighting: [Lighting]  
Camera: [Camera / lens / angle]  
Style: [Visual treatment]  
Detail: [Texture / mood / realism]  
Format: [Aspect ratio / platform]

---

## Prompt Design Loop

**Write → Test → Review → Identify Failure → Refine → Save → Reuse**

A useful prompt becomes a reusable asset when its successful structure is documented.
