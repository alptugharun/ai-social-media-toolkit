- **tr/** — Turkish localization for the Alptuğ Harun Instagram audience and Türkiye-focused distribution.

Both variants contain exactly eight 1080×1350 (4:5) slides.

The campaign deliberately distinguishes repository/source verification from runtime verification. It does not claim guaranteed virality, universal compatibility or income.
