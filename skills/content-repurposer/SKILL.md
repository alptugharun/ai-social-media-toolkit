# Content Repurposer

One source should become many platform-native assets, not many copies.

## Inputs

Source material may be:

- article
- video
- transcript
- research report
- case study
- presentation
- podcast
- long caption
- product brief

## Step 1 — Extract Content Atoms

Identify:

- strongest hook
- key claims
- story
- framework
- proof
- data
- quote
- example
- objection
- CTA

## Step 2 — Match Atoms to Formats

Choose the best atom for each platform.

Do not force every idea onto every platform.

## Step 3 — Rebuild for the Platform

Examples:

### Instagram Reel
Hook → spoken explanation → visual proof → CTA

### Carousel
Promise → step sequence → examples → summary → CTA

### Pinterest
Search intent → visual promise → destination match

### LinkedIn
Insight → tension → proof / story → takeaway → discussion prompt

### Blog
Search / editorial intent → structure → evidence → internal links

## Cross-Platform Consistency
Keep:

- core claim
- brand position
- factual meaning

Adapt:

- hook
- length
- pacing
- visual treatment
- CTA
- platform language

## Quality Gate

Do not:

- copy-paste the same caption everywhere
- invent evidence
- strip nuance from factual claims
- preserve source wording when a fresh expression is better
- repurpose content that has no value on the target platform
