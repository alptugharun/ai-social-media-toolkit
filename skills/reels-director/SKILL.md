# Reels Director

Build short vertical videos from strategy first.

Default to one focused idea per video.

## Inputs

Use available creator context.

Identify:

- Objective
- Audience
- Platform
- Core idea
- Evidence / source
- Desired duration
- Available production assets
- CTA

If duration is not specified, choose the shortest duration that communicates the idea clearly.

## Script Architecture

Use:

**Hook → Context → Value → Proof / Example → CTA**

Write for spoken language.

Prefer:

- short sentences
- natural transitions
- one dominant message
- minimal repetition
- mobile-first language

## Hook Lab

Generate multiple hooks internally.

Select the final hook using:

- immediate relevance
- specificity
- curiosity
- credibility
- fit with the actual content

Do not use clickbait that the body cannot deliver.

## Shot Plan

Create a time-coded table:

| Time | Spoken line | Shot | B-roll / screen | On-screen text |
| --- | --- | --- | --- | --- |

Possible visual modes:

- Talking head
- Screen recording
- Canva demonstration
- Product detail
- AI-generated visual
- B-roll
- Before / after
- Environment
- Close-up

## Visual Continuity

For generated visual series, identify which variables must remain constant:

- subject / character
- pose logic
- camera direction
- lighting logic
- scene structure
- brand treatment

Change only the variables the concept requires.

## Editing Direction

Every edit must do at least one job:

**Clarify → Maintain Attention → Improve Rhythm → Support Meaning**

Remove:

- dead space
- unnecessary intros
- repeated points
- decorative transitions with no purpose

## Publish Pack

Return:

- Cover title
- Caption direction
- CTA
- Keywords
- Optional hashtags
- Repurposing opportunities

## Review Gate

Check:

- hook pays off
- claims are supported
- script sounds natural aloud
- visuals support meaning
- subtitles are accurate
- no obvious AI artifacts
- CTA matches objective
- export is correct for the platform

## Measurement

Match KPI to objective:

- Awareness → reach / views
- Education → watch time / saves
- Shareability → shares
- Authority → profile visits / follows
- Traffic → outbound clicks
- Conversion → leads / sales
