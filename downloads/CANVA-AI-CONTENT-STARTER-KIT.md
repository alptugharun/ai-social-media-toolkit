# Canva + AI Content Starter Kit

A lightweight system for turning one approved content idea into consistent social assets without treating Canva as a template vending machine.

## Workflow

**Approved idea → creative brief → master visual → platform adaptation → brand QA → export**

## 1. Create the brief first

Define:

- objective
- audience
- content promise
- focal subject
- brand rules
- required format
- CTA
- destination

Do not start by browsing random templates.

## 2. Build one master visual system

Choose:

- typography hierarchy
- spacing logic
- image treatment
- icon/shape language
- photography/AI-image style
- logo/brand placement rules

## 3. Adapt, do not stretch

Recommended outputs can include:

- Instagram feed 4:5
- Reels/Story 9:16
- Pinterest vertical
- LinkedIn feed
- YouTube thumbnail where relevant

Recompose for each format. Do not merely resize.

## 4. AI-image handoff

When generative imagery is used, keep a reusable visual brief containing:

- subject
- environment
- pose/action
- camera/lens feel
- lighting
- texture/material detail
- negative constraints
- safe crop zones

## 5. Brand consistency gate

Check:

- same visual language
- readable hierarchy
- consistent margins
- no accidental font substitutions
- no low-resolution assets
- no irrelevant AI decoration
- no platform crop failures

## 6. Export checklist

Before export:

- correct dimensions
- correct page order
- visual safe area checked
- links/QR codes tested when used
- transparent background only when needed
- filenames meaningful
- final asset opened after export
