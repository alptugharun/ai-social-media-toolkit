# Reels Production Starter Kit

A 30–35 second short-form workflow from idea to review-ready production package.

## Production chain

**Idea → hook → spoken script → shot plan → visual assets → edit → caption → QA**

## Timing model

### 0–3 sec — Hook

One clear tension, problem or result.

### 3–10 sec — Context

Explain why the viewer should care.

### 10–25 sec — Value

Deliver the actual useful point.

### 25–32 sec — Payoff

Close the loop opened by the hook.

### Final seconds — CTA

One action only.

## Voiceover checklist

- natural spoken language
- short sentences
- one main idea
- no article-style introduction
- no fake urgency
- no unsupported numbers
- no repeated CTA

## AI visual brief

For generated imagery define:

- subject
- pose/action
- environment
- camera distance
- lighting
- material/skin/fabric texture
- visual realism level
- negative constraints
- 9:16 composition

Keep the scene stable when testing visual styles so the style—not the underlying concept—changes.

## Edit checklist

- first useful visual appears immediately
- no dead air
- cuts support speech rhythm
- subtitles remain readable
- B-roll explains rather than decorates
- music does not overpower voice
- ending does not drag

## Publishing package

Prepare separately:

- caption
- CTA
- hashtags only when relevant
- cover concept
- accessibility/alt-text notes where supported
- AI-content disclosure when platform rules or context require it

## QA gate

Before publishing ask:

1. Is the first 3 seconds understandable without context?
2. Can the main point be repeated in one sentence?
3. Is every factual claim supported?
4. Does each shot serve the message?
5. Does the CTA match the objective?

## Core rule

**A short Reel is not a compressed article. It is one clear idea designed for speech, movement and retention.**
