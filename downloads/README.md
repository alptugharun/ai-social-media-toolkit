# Creator Materials

A practical download layer for creators, strategists and small teams who want useful AI-assisted workflows without installing the full Agent Skills system.

This directory is intentionally different from a generic prompt dump.

Each resource should have:

- a clear job-to-be-done
- required inputs
- a reusable workflow
- an expected output
- a human-review gate
- an example or quality check when useful

## Open core vs. future premium companions

The public repository must remain genuinely useful.

Potential paid companions are not simply “more prompts.” They should reduce setup time, connect more steps, provide editable operating systems, or include implementation/support.

Candidate premium lanes to validate before building deeply:

- Creator Prompt OS
- Pinterest Growth OS
- Reels Production OS
- Canva + AI Content Factory
- Creator Automation Vault
- AI Creator Operating System
- implementation and customization services

These are product hypotheses, not guaranteed offers. Pricing, checkout and hosted infrastructure should be added only after real-user demand is observed.

## Product rule

**Free teaches and proves the workflow. Premium should remove friction, connect the workflow and save meaningful time.**

Do not cripple the open-source core just to create an upgrade path.
