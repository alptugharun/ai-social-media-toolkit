# Pinterest Growth Starter Kit

A compact workflow for building Pinterest content from evidence, search intent and destination fit.

## Workflow

**Evidence → keyword cluster → Pin roles → visual system → destination match → publish → measure → expand winners**

## 1. Evidence

Use official Pinterest trend/API evidence when available, or clearly labeled user-provided keyword evidence.

Do not invent:

- search volume
- trend percentages
- “viral” status
- competition scores

## 2. Build one keyword cluster

Organize the evidence into:

- broad intent
- problem intent
- inspiration intent
- seasonal intent
- commercial intent

## 3. Create a 7-Pin cluster

1. **Hero Pin** — strongest visual summary
2. **Educational Pin** — teaches one useful idea
3. **Checklist Pin** — save-oriented utility
4. **Comparison Pin** — helps a decision
5. **Seasonal Pin** — time-sensitive variation
6. **Search-led Pin** — explicit keyword intent
7. **Visual-discovery Pin** — high visual novelty without losing relevance

## 4. Define each Pin before design

For every Pin write:

- target query/intent
- content promise
- visual focal point
- destination URL
- CTA
- KPI

## 5. Destination-match gate

Do not send:

- nail-art Pins to an unrelated agency page
- pet/lifestyle Pins to an AI service page
- seasonal inspiration Pins to a generic homepage when a specific destination exists

The Pin promise and landing page must match.

## 6. Visual-system rule

Keep a recognizable system across the cluster:

- consistent subject treatment
- repeatable composition logic
- deliberate aspect ratio
- original imagery
- variation in angle/use case rather than random styling

## 7. Measure

Use real analytics when available:

- impressions
- saves
- outbound clicks
- close-ups
- destination engagement

## 8. Expand winners

When one Pin wins, test the mechanism:

- new query
- new seasonal angle
- new crop/composition
- new content promise

Do not simply duplicate the same Pin.
