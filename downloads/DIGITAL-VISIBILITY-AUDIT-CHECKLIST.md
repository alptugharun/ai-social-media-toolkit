# Digital Visibility Audit Checklist

A standalone checklist for reviewing the digital presence of a person, creator or brand.

Created by **Alptuğ Harun**.

## Identity

- [ ] Full name is consistent
- [ ] Professional title is clear
- [ ] Short biography is current
- [ ] Long biography is current
- [ ] Profile image is professional
- [ ] Location is consistent where relevant
- [ ] Brand and project relationships are clear

## Website

- [ ] Primary domain is defined
- [ ] Homepage explains who / what / why
- [ ] About page exists
- [ ] Author page exists when relevant
- [ ] Contact information works
- [ ] Main professional profiles are linked
- [ ] Important pages have internal links
- [ ] Mobile experience is usable

## Search

- [ ] Sitemap exists
- [ ] Sitemap contains intended indexable URLs
- [ ] robots.txt is reviewed
- [ ] Important pages are not accidentally noindexed
- [ ] Canonical URLs are correct
- [ ] Search Console is configured
- [ ] Bing Webmaster Tools is configured
- [ ] Indexing issues are monitored

## Structured Identity

- [ ] Person / Organization data is accurate
- [ ] Relevant structured data matches visible content
- [ ] Official profiles are connected where appropriate
- [ ] Project relationships are clearly described

## Profiles

- [ ] LinkedIn is current
- [ ] GitHub is current
- [ ] Portfolio is current
- [ ] Social profiles link to the official website
- [ ] Old profile information has been corrected

## Content

- [ ] Core topic clusters are defined
- [ ] Important expertise areas have supporting content
- [ ] Case studies show real work
- [ ] Duplicate publishing is controlled
- [ ] Evergreen content is periodically reviewed

## Authority

- [ ] Independent mentions are documented
- [ ] Media coverage is organized
- [ ] Important claims have supporting evidence
- [ ] Public resources provide original value

## Technical Quality

- [ ] Broken links are checked
- [ ] Redirects are maintained
- [ ] Images are optimized
- [ ] Alt text is used appropriately
- [ ] Accessibility is reviewed
- [ ] Mobile usability is tested

## Monitoring

- [ ] Brand search results are reviewed
- [ ] New mentions are monitored
- [ ] Search performance is checked
- [ ] Outdated information is corrected
- [ ] Referral traffic is reviewed
