# Creator Frame Studio roadmap

This roadmap separates useful product work from marketing claims.

## v0.2.x — harden the beta
- [x] Multi-platform canvas presets
- [x] Drag, zoom, fit/cover, rotate and flip
- [x] Editable text layers
- [x] Conservative inner-area guides
- [x] 3:4, 1:1 and circle crop previews
- [x] Single image export
- [x] Multi-format ZIP export
- [x] Project save / reopen
- [x] TR / EN interface
- [ ] Browser CI with interaction-level smoke tests
- [ ] Verify current UI on recent Android and iOS browsers
- [ ] Publish reproducible screenshots from the GitHub build

## v0.3 — creator workflow
- [ ] Snap lines and alignment helpers
- [ ] Title / face / CTA guide presets as clearly labeled editorial presets
- [ ] Brand kit: colors, type scale and logo placement
- [ ] Reusable carousel templates
- [ ] Apply a text style across selected pages
- [ ] Better keyboard controls and accessibility review
- [ ] Faster mobile editing

## v0.4 — production workflow
- [ ] Batch import and naming rules
- [ ] Export manifest for client delivery
- [ ] Optional local template library
- [ ] Format-change regression tests
- [ ] Platform-spec review log with source date

## Explicit non-goals until there is evidence
- No “viral score”.
- No fake AI quality percentage.
- No claim that a guide is an official safe zone unless the platform publishes that exact rule.
- No automatic publishing without an explicit permission model and separate integration work.
