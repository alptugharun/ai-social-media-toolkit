# AI Social Media Toolkit v0.1.0-alpha.1

**First public alpha: creator operations you can inspect, run and improve.**

This prerelease packages the toolkit's first coherent public surface around one loop:

**Signal → Research → Strategy → Content → Creative → Review → Distribution → Measurement → Winner Expansion**

## Try the proof first

```bash
git clone https://github.com/alptugharun/ai-social-media-toolkit.git
cd ai-social-media-toolkit
python tools/two_minute_demo.py
```

The demo uses synthetic repository data and runs without third-party Python packages or API keys.

## Install the Agent Skills

```bash
npx skills add alptugharun/ai-social-media-toolkit
```

Browse before installing:

```bash
npx skills add alptugharun/ai-social-media-toolkit --list
```

## What ships in this alpha

- **17 Agent Skills** for creator operations, Reels, Pinterest, repurposing, brand voice, influencer fit, opportunity research, local intelligence and monetization architecture.
- **Runnable Python tools** for content prioritization, social outlier analysis, opportunity radars, installation, traction review and bounded failure diagnosis.
- **GitHub Actions automation** for validation, research radars, health monitoring, traction review and bounded self-healing.
- **Creator Materials Hub** with prompt systems, assistant blueprints, automation starters, Pinterest, Reels, Canva + AI and Creator OS starter resources.
- **Complete human usage field manual** covering setup, first requests, inputs, expected outputs, common mistakes and troubleshooting.
- **Two-minute proof demo** wired into CI.

## What this alpha is not

- not a virality predictor;
- not an autonomous social publisher;
- not a promise of reach or revenue;
- not a replacement for human review;
- not a reason to expose credentials or private client data.

Live platform data requires valid official access where documented. Runtime behavior can differ between Agent Skills hosts.

## The feedback that matters

## Why prerelease?

The core is runnable and tested, but external installation, repeat use and cross-runtime behavior still need real-world validation. This alpha is designed to collect that evidence before a stable release.
