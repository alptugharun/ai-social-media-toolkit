# AI Social Media Toolkit v0.3.0-alpha.1

**Proof-first creator systems, a live local-first tool, and measurable download assets.**

This prerelease packages the strongest work that landed after v0.2.0-alpha.1 into a cleaner distribution surface for creators and AI builders.

## Start with the proof

No API key or paid model is required for the local first-run check:

```bash
git clone https://github.com/alptugharun/ai-social-media-toolkit.git
cd ai-social-media-toolkit
python tools/first_run_check.py
```

## What is new

### Creator Context Builder

A new foundation Agent Skill builds one reusable creator/brand context while keeping:

- verified facts,
- user preferences,
- observed writing patterns,
- hypotheses,
- stale metrics,
- approval boundaries

separate.

It also has explicit privacy rules for secrets and private client data.

### Creator Frame Studio

The browser-local Creator Frame Studio is available as both:

- a live GitHub Pages beta;
- an offline downloadable ZIP.

It supports multi-format framing, editable text, guide profiles, preflight checks and exports without requiring an account or API key.

### Trust and safety surfaces

The current repository also includes:

- MCP Permission Inspector for local config review before first connection;
- Agent Skill Safety Auditor;
- explicit MCP tool annotations and test coverage;
- immutable GitHub Action references;
- public adoption evidence and Real User Lab paths.

## Downloadable assets

This release intentionally ships measurable GitHub release assets:

- `agent-skills-v0.3.0-alpha.1.zip` — all 19 Agent Skills plus shared installation/context references;
- `creator-context-builder-v0.3.0-alpha.1.zip` — the new foundation skill only;
- `creator-frame-studio-v0.3.0-alpha.1.zip` — offline static creator tool;
- `ai-social-media-toolkit-plugin-0.6.0.zip` — skills-only Agent Plugin bundle;
- `SHA256SUMS.txt` — integrity hashes.

GitHub's per-asset download counts can now be tracked separately from clone telemetry.

## Install Agent Skills

All skills:

```bash
npx skills add alptugharun/ai-social-media-toolkit
```

Only the context foundation:

```bash
npx skills add alptugharun/ai-social-media-toolkit --skill creator-context-builder
```

## Current evidence boundary

This release proves repository behavior through tests, reproducible local checks and packaged artifacts.

It does **not** claim:

- that clone events equal users;
- guaranteed compatibility with every agent host;
- guaranteed reach, virality, revenue or GitHub Trending placement;
- independent adoption until external users report it.

Use the public Adoption Ledger and Real User Lab for that evidence.
