# 30–35 Second Reels Director

## Overview

Turn one verified idea into a spoken short-form package with timing, shots and QA.

## Use When

- Reels, Shorts or TikTok production
- AI visual + CapCut production

## Do Not Use When

- the topic needs long-form nuance
- key claims are unverified

## Required Inputs

- **TOPIC**: one idea
- **AUDIENCE**: specific viewer
- **EVIDENCE**: facts allowed
- **GOAL**: save, share, click, authority, etc.

## Copy/Paste Prompt

```text
Create a 30–35 second vertical-video package.

TOPIC: [TOPIC]
AUDIENCE: [AUDIENCE]
GOAL: [GOAL]
ALLOWED FACTS: [EVIDENCE]

Return:
- 0–3s hook
- timed spoken script
- shot/B-roll plan
- AI visual brief per generated shot
- CapCut edit notes
- cover title
- one CTA
- final QA

Use natural spoken Turkish unless another language is requested. Do not add facts outside ALLOWED FACTS.
```

## Expected Output

- timed voiceover
- shot plan
- visual briefs
- edit notes
- QA

## Quality Gate

- [ ] Fits 30–35 seconds aloud
- [ ] One main idea
- [ ] Every factual claim supported

## Example Input

```text
TOPIC: Why AI product photos look fake
AUDIENCE: beginner creators
GOAL: saves
EVIDENCE: [3 verified points]
```

## Troubleshooting

- **Script reads like an article** → shorten sentences and remove setup
- **Too many scenes** → merge shots around the single payoff
