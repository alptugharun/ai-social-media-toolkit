# Pinterest 7-Pin Cluster Builder

## Overview

Turn one search opportunity into seven Pins with distinct intent, visual roles and destinations.

## Use When

- building a Pinterest content cluster
- mapping search intent to traffic destinations

## Do Not Use When

- you have no keyword/trend evidence
- all seven Pins would point to unrelated destinations

## Required Inputs

- **TOPIC**: cluster theme
- **KEYWORDS**: real keyword evidence
- **DESTINATIONS**: available destination URLs/pages
- **SEASON**: if relevant

## Copy/Paste Prompt

```text
Build a 7-Pin Pinterest cluster.

TOPIC: [TOPIC]
KEYWORD EVIDENCE: [KEYWORDS]
DESTINATIONS: [DESTINATIONS]
SEASON: [SEASON]

Create seven distinct roles:
1. Hero
2. Educational
3. Checklist
4. Comparison
5. Seasonal
6. Search-led
7. Visual-discovery

For each: intent, title idea, visual focal point, destination, CTA and KPI.
If evidence is incomplete, label the item as a hypothesis. Do not invent Pinterest search volume.
```

## Expected Output

- 7 distinct Pin jobs
- destination mapping
- visual differentiation
- KPI per Pin

## Quality Gate

- [ ] No duplicate intent
- [ ] Destination matches promise
- [ ] No invented trend metrics

## Example Input

```text
TOPIC: autumn nail art
KEYWORDS: [provided terms]
DESTINATIONS: [article/tutorial pages]
SEASON: September–October
```

## Troubleshooting

- **Pins look identical** → change role/intent before styling
- **No matching destination** → hold that Pin or create the destination first
