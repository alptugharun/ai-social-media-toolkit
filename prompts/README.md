## How to use

1. Open the prompt file for your job.
2. Fill only the required inputs.
3. Copy the **Copy/Paste Prompt** section into ChatGPT, Claude, Gemini, Grok or another compatible assistant.
4. Supply your real inputs.
5. Compare the result with **Expected Output** and **Quality Gate**.
6. If it fails, use **Troubleshooting** before rewriting the whole prompt.

## Model note

Prompts are written to be portable. Model behavior still differs. A prompt tested with one provider is not automatically verified on every provider.
